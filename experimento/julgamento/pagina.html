Julgamento manual dos casos

Antes de começar

Cada caso é a resposta de um modelo de linguagem a uma variante em que um code smell (CS) foi injetado. Você vê a definição do CS, o código injetado e as citações da resposta que apontam esse código. O modelo que respondeu não é mostrado.

Pergunta de cada caso: alguma das citações aponta, no código injetado, o CS descrito? Responda Sim, Não ou Dúvida, e use o comentário quando ajudar a discussão das divergências. Julgue sem consultar o outro juiz.

Como decidir:

  1. Julgue a resposta, não o código: o CS foi injetado e está lá; a pergunta é se alguma citação da resposta o aponta.
  2. Sim: a citação aponta as linhas injetadas (ou o arquivo novo), e o nome ou a justificativa descreve o CS mostrado, mesmo com outras palavras.
  3. Não: as citações no código injetado tratam de outro problema (outro CS, segurança, desempenho, arquitetura), ainda que apontem as linhas certas.
  4. Nome genérico (como Large Class, código morto ou Switch Statements): decida pela justificativa. Se ela descreve a característica que define o CS mostrado (para Excessive Class Length, o número de linhas), é Sim; se descreve outra (por exemplo, responsabilidades demais), é Não; se não dá para saber, é Dúvida, com um comentário.

Antes dos casos, a página mostra exemplos comentados, que não contam no resultado.

Os votos ficam salvos neste navegador enquanto você julga. De vez em quando, e no fim, clique em Baixar votos (CSV): o arquivo é a cópia de segurança e é ele que você manda. Se trocar de navegador ou de computador, escolha o seu número de juiz, use Retomar de um CSV baixado e continue de onde parou. Atalhos: S, N e D votam; as setas mudam de caso.
